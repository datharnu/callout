# Logo sources

These marks name the services Callout is built with. They appear in the landing page's hero line, the small "Built with"
row under the hero buttons, the logo ticker under the hero window, and the "Bybit Demo" pill on /try. They are trademarks of their owners. They are used here only to name the integrations,
not to suggest an endorsement. Downloaded on 27 Nov 2026.

| File | Mark | Source | What changed |
| --- | --- | --- | --- |
| `even-realities.svg` | Even Realities wordmark | The inline logo on https://www.evenrealities.com/ (`aria-label="Even Realities Logo"`) | `currentColor` set to ink `#15191a`; `xmlns` and an accessible label added; the site's CSS classes removed |
| `even-realities-icon.svg` | Even Realities "E" symbol | Same file as `even-realities.svg` | Only the viewBox changed, cropped to the symbol at the left of the wordmark (used at 14px in the small "Built with" row) |
| `bybit.png` | Bybit wordmark (orange "I") | Bybit's official GitHub organisation avatar, https://github.com/bybit-exchange.png (bybit.com does not serve its logo to scripts, and Bybit publishes no SVG) | Cropped to the wordmark; the dark background made transparent; white letters set to ink, the orange "I" kept orange (`#F7A600`) |
| `telegram.svg` | Telegram paper plane | Simple Icons `telegram` (https://simpleicons.org/?q=telegram, CC0), v16.38.1 | Fill set to ink |
| `claude.svg` | Claude mark | Simple Icons `claude` (CC0), v16.38.1 | Fill set to ink |
| `elevenlabs.svg` | ElevenLabs mark | Simple Icons `elevenlabs` (CC0), v16.38.1 | Fill set to ink |

The marks are shown in grey (CSS `grayscale`, with 0.6 opacity in the small row and 0.72 in the ticker); the small row shows each mark in its own colours on hover.
